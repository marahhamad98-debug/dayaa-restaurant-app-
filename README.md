- Android وiPhone عبر Expo / React Native
- الموقع: دمشق، المزة 86، مدرسة
- هاتف: 0116622204
- موبايل: 0936379661
- الدفع: نقداً عند الاستلام
- خيارات الاستلام: توصيل للمنزل أو استلام من المطعم
- قائمة المعجنات والسندويشات من صور القائمة المرسلة

## تنبيه حول الأسعار
الأسماء المطبوعة واضحة، لكن الأسعار مكتوبة بخط اليد في عمودين وهي غير واضحة بما يكفي لاستخراجها بثقة. لذلك لم أضع أسعاراً تخمينية في التطبيق. تظهر حالياً عبارة أن السعر يؤكد هاتفياً. أرسل الأسعار مكتوبة أو صورة أوضح، مع توضيح معنى العمودين، لأضيفها بدقة.

## تشغيل النموذج
1. تثبيت Node.js.
2. تشغيل `npm install`.
3. تشغيل `npx expo start`.
4. فتح QR بواسطة Expo Go أو تشغيل محاكي.

## قبل استقبال طلبات فعلية
الطلبات في هذه النسخة تجريبية ومحلية على الجهاز. يلزم Backend وقاعدة بيانات ولوحة إدارة وربط إشعارات/واتساب أو شاشة طلبات لدى المطعم، إضافة إلى اختبار التطبيق وإعداده للنشر على المتاجر.
