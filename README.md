# مطعم ومعجنات الضيعة – تطبيق تجريبي

تطبيق React Native مبني باستخدام Expo، بواجهة عربية RTL، ويعمل كأساس مشترك لأجهزة Android وiPhone.

## التشغيل
1. ثبّت Node.js وادخل إلى مجلد المشروع.
2. نفّذ `npm install`.
3. نفّذ `npx expo start`.
4. افتح التطبيق باستخدام Expo Go أو شغّل محاكي Android/iOS.

## الموجود حالياً
- واجهة رئيسية عربية وتصنيفات وبحث.
- قائمة منتجات تجريبية وأسعار بالليرة السورية.
- سلة مع زيادة/إنقاص الكميات.
- نموذج بيانات العميل واختيار التوصيل أو الاستلام.
- سجل طلبات محلي تجريبي.

## مهم قبل الإطلاق الحقيقي
هذا نموذج أولي قابل للتشغيل وليس خدمة طلبات منشورة. الطلبات حالياً تُحفظ داخل حالة التطبيق فقط، ولا تصل إلى المطعم. يلزم قبل النشر:
- تأكيد قائمة المنتجات والأسعار والصور.
- إضافة رقم هاتف وواتساب المطعم وساعات العمل ورسوم التوصيل ومناطق التغطية.
- ربط Backend وقاعدة بيانات ولوحة إدارة آمنة لاستقبال الطلبات.
- إعداد سياسة الخصوصية وشروط الاستخدام.
- إعداد حسابات المطورين ومتطلبات النشر في Google Play وApple App Store.
- مراجعة العملة والأسعار وفق الأسعار الفعلية للمطعم.

الأسعار والأصناف الحالية أمثلة مؤقتة وليست أسعاراً معتمدة من المطعم.
